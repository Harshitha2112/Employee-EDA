# 💰 San Francisco Employee Salary Analysis

## 📌 Project Overview

This project analyzes the **San Francisco employee salary dataset** using Python and Pandas.

The goal is to explore employee salaries, job titles, pay components, and salary trends across different years and job roles.

## 📊 Dataset

- **Source:** Kaggle – San Francisco Salaries Dataset
- **Rows:** 148,654
- **Columns:** 13
- **Years:** 2011–2014
- **Agency:** San Francisco

### Main Columns

- EmployeeName
- JobTitle
- BasePay
- OvertimePay
- OtherPay
- Benefits
- TotalPay
- TotalPayBenefits
- Year

## 🔍 Analysis Performed

The project includes:

- Exploring the dataset structure and dimensions
- Checking column names and data types
- Identifying missing values
- Removing unnecessary columns
- Cleaning and converting salary-related data
- Finding the employee with the highest BasePay
- Calculating average BasePay for each year
- Calculating average BasePay for different JobTitles
- Finding the most common job titles
- Filtering salary information based on specific job roles

## 🛠️ Technologies Used

- Python
- Pandas
- Jupyter Notebook
- Anaconda
